## 提交与回退约定

- **每功能一个提交**：一个功能 = 一份 `docs/plan-*.md` 方案 + 实现 + 测试 + 一个独立 `feat:` 提交（方案文档随该提交或紧邻提交入库）。
- **撤销单个功能**：`git revert <sha>`（生成反向提交，历史保留）。
- **整体回到某版本**：`git reset --hard <sha>`（丢弃其后全部改动，慎用）。
- **查版本**：`git log --oneline` 找到目标 sha。
- 状态列取值：未开始 / 草案进行中 / 草案 / 定稿 / 已实施。
