## 二、顺手修复的存量问题

1. `AnnotatedMarkdown` 的 memo 被内联回调击穿——任何状态变化都会触发标注全量重绘（富文档卡顿的隐形元凶）。
2. 全库标注 tab 在窄侧栏下被搜索框内在宽度撑破、筛选 chips 被裁切。
3. "读完接着读"卡片关闭后因缓存推荐会复活（本轮新功能自身的验收发现）。
4. 阅读设置面板内容超出视口后底部选项不可达（无内部滚动）。

## 四、已知限制与待人工验收

自动化环境覆盖不到、需要真机确认的 13 项（每条的验证步骤见 `docs/roadmap-innovations.md`「总验收」章节）：

- **桌面真机（9 项）**：MRU 失效路径表现；PDF 区域卡片框选手感与提质清晰度；PDF 双页真实文档渲染与懒渲染预算；聚焦模式在 PDF 场景；书架 PDF/EPUB 封面 IPC 链路；增量重读 watcher 链路；报告卡片用真实统计数据；竖排在有头 WebView2 下的合成器伪影确认；打字机滚动长文手感。
- **Web 真实部署（4 项）**：Pages 子路径 PWA 四步验证；iOS Safari 与 Android Chrome 真机手势；Firefox 回落行为。

另：竖排模式在 headless Chromium 截图中发现一处合成器绘制伪影（布局与交互均正确，CSS 侧无解），实验档的第一响应是关闭开关即完全恢复。

## 五、如何回退

- 撤销单个功能：`git revert <上表对应 sha>`（保留其后的其他功能）。

- 查看版本流水：`git log --oneline`。
