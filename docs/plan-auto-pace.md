# 自感应按段推进（plan-auto-pace）

- 状态：**已实施**（`c26a587`；开关在阅读设置「实验 / 进阶」分组）

一句话：聚焦模式之外的「自动推进」按段停留后跳吸下一段；底速复用个人字/分钟校准；会话内根据提前滚/回退自感应调速；无摄像头、无匀速缓滚。

## 边界

- 与聚焦三件套同禁用通道（竖排 / PDF 原版式）
- TTS 控制条打开时挂起；播放中打字机让位
- 零后端 / 零 IPC；偏好 `autoPaceEnabled` + `autoPaceBias` 持久化

## 控制面（隐式）

- 右下角默认只显示半透明播放/暂停胶囊，不盖住大块正文
- 悬停或 `:focus-within` 时展开状态文案、节奏滑杆与关闭
- 播放中比暂停更淡；空格暂停/继续，Esc 关闭

- 长 Markdown 连续推进 5+ 分钟，跳吸不抖、不连跳短段
- 故意抢滚/回退，节奏暗示收敛到偏快/偏慢
- 切窗、划词、拖滚动条暂停；松手/回焦后可继续
- 与朗读条、读完接着读、竖排置灰交叉无冲突
