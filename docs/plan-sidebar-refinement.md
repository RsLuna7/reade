# 侧边栏精修方案

状态：方案待评审，尚未实施。  
日期：2026-09-07  
目标：让侧边栏更像清楚、安静的书目；减少重复描边，改善按钮与菜单的操作手感。

## 1. 已确认的产品方向

- 保留 Reade 的纸感、砖红强调色和品牌识别度，以现有界面为基础精修。
- 文档名称是首要信息；阅读时间预估保留，作为书本长度的直观指标，常驻显示。
- 时长放到书名下方，和文件格式等次要信息组成说明行。
- 文档名称最多两行，同类文档行保持统一高度；悬停不撑开列表、不挤动相邻项。
- 动效用于确认操作、说明展开关系和保持状态连续；高频选文档及时响应。
- 本轮先做桌面侧边栏。正文、右侧目录、主页、统计页面不纳入视觉改版。

侧边栏承担操作导航，中央正文承担阅读。两者沿用同一主题，但侧边栏不采用大标题、装饰卡片或营销页入场效果。

## 2. 依据与问题

依据为用户提供的已加载书库截图、当前源码和桌面空书库浏览器检查。先前的独立 HTML 小样只用于方向探索，不作为实现模板。

| 现状 | 影响 | 本轮处理 |
| --- | --- | --- |
| 28px 格式标签和右侧时长与标题争用同一行 | 相似教材名被截断，难以辨认 | 标题独占主要宽度，格式与时长移入说明行 |
| 库按钮、格式标签、切换器和分隔线反复强调边界 | 组件拼装感较重 | 用留白、底色和文字层级分组，减少装饰边框 |
| 纸感主题部分次要文字对侧栏底色约 2.77:1 | 信息过淡 | 提升必要文字对比度，按角色分配颜色 |
| 动效覆盖不一致；部分弹层只有动效类名 | 有些交互柔和，有些直接跳变 | 为本轮控件明确状态与过渡实现 |
| 底栏将导航与外观操作等权混排 | 分组与可点击性不够明确 | 用空间分成导航组和外观组 |

已有搜索快捷键、键盘树导航、语义状态、当前项标识和动效偏好应继续保留。列表空白不构成缺陷，不通过添加内容填满。

## 3. 布局与信息层级

```text
Reade                         品牌区

大三上·教材  ▾          刷新   当前书库
搜索标题与正文        Ctrl K  搜索

▸ 合集                    +   合集入口

文档                 列表 书架

▸ 专业英语测验                文件夹

  223343916-机械工程基础       文档：标题最多两行
  第二行标题（需要时）
  PDF · 约 7 小时             常驻说明行

  有限与无限的游戏
                              标题区预留第二行高度
  EPUB · 约 141 分钟

……

首页  统计         纸感 ▾  月亮
```

以上为结构示意，正式界面沿用 SVG 图标；不把文字示意或字符图标直接搬进产品。

### 顶部

- 保留现有品牌图形与字标，适度收紧品牌区垂直间距。
- 当前书库呈现为名称加展开提示；默认去掉明显外框，悬停和展开时出现轻底色。无最近书库时沿用原选择目录行为。
- 刷新仍在库名右侧，保留加载与禁用反馈。
- 搜索保持独立浅底色和清楚的聚焦反馈，保留现有措辞与 Ctrl+K 提示。
- 合集保持现有位置与折叠能力；折叠时是一条轻量导航行。
- 将“文档”和列表／书架切换放在同一行，切换保留文字标签与明确选中态，不再占用一整层带框容器。

### 文档列表

- 文件夹保持紧凑单行，展开符号由加减号改为方向箭头。
- 文档采用两行标题区加一行说明区。标题短时保留预留高度，说明行位置与其他文档一致。
- 建议初始参数：标题 13px、行高 19px；说明 11px、行高 16px；标题与说明间距 3px；上下内边距各 8px。文档总高约 73px，文件夹高约 34–36px。
- 以上数值是首轮视觉验收起点，使用相对字号与一致尺寸变量表达；高 DPI 和缩放后不得裁字。
- 同一布局中默认不随内容、悬停或选中改变行高。此选择会减少一屏可见文档数，以提高长标题辨认为目标，不另加密度设置。
- 说明行显示“PDF · 约 7 小时”“EPUB · 约 141 分钟”。保留现有估算值、措辞与计算逻辑，不推断剩余时长、不改成阅读进度。
- 扫描版继续显示“PDF · 扫描版”；无法估计沿用现有状态，不显示虚假数值。
- 已阅标记保留在说明行；较窄时可缩短其视觉表达，但需保留可访问名称，不能挤压书名或隐藏时长。
- PDF／EPUB／MD 取消描边徽章，用清楚的小字提示格式。
- 格式标签当前同时承担拖动排序入口；调整位置后必须保留可操作的拖动热区与排序行为，不能只删掉相关元素。
- 当前项采用轻量砖红底色与中等字重。先保留一处细小位置标记，以确保选中状态不只靠颜色；避免同时叠加外框、阴影等强调。

### 长标题

- 默认最多两行省略；有实际溢出时，悬停约 350ms 后显示静止的完整标题提示。
- 键盘聚焦同样能显示全名，Esc 可关闭；提示不抢焦点、不阻挡点击，不撑开列表。
- 提示需要避免被侧栏滚动容器裁切，并在滚动、切文档或移出后清理。
- 此处替换文档树的循环跑马灯；其他复用 OverflowMarquee 的界面保持原行为。
- 保留现有“本夹文档全名列表”和对应快捷键，作为大量相似长文件名的辅助路径。

### 底部

- 左侧为首页／统计导航，右侧为风格／明暗切换；以间距分组，保留现有功能和状态。
- “纸感”加展开箭头，明确它是可操作入口。
- 明暗主题下都要清楚区分默认、悬停、焦点、选中和禁用状态。
- 底部状态消息仍有独立位置；读取或索引状态变化不应导致按钮上下跳动。

## 4. 视觉规格

- 优先保留现有主题色与字体体系，不引入远程字体或新的图标依赖。
- 组件表面分为侧栏底色、轻量悬停色、当前项色、浮层色；阴影主要表达浮层，不给每个按钮和文件行添加阴影。
- 边框只用于必要的容器边界、键盘焦点与确有必要的输入提示。
- 普通信息文字按至少 4.5:1 的对比度目标验收；小字不可因“次要”而不可读。图标与状态提示按各自语义检查。
- 优先用侧栏专属角色变量改善次要文字，避免直接修改全局 muted 色造成正文、其他视图全面变化。
- 保留现有圆角语言，减少同时出现的独立小盒子数量；不引入大面积毛玻璃、噪点或光晕。

## 5. 动效与交互规格

| 操作 | 建议反馈 | 约束 |
| --- | --- | --- |
| 普通图标按钮悬停 | 约 120ms 的底色／颜色变化 | 不突然出现强边框，不改变占位 |
| 普通按钮按下 | 约 100–140ms，轻微缩放至 0.98 或表面变化 | 文档整行不缩放；不延迟事件处理 |
| 选中文档 | 立即更新语义状态，底色短过渡 | 不逐项飞入，不等动画完成再读取 |
| 列表／书架切换 | 选中标识约 160–180ms 过渡 | 不平滑挪动所有文档；保持可快速连续切换 |
| 文件夹展开 | 箭头短旋转，必要时子组短淡入 | 不按文档数量串行播放，不用巨大 max-height 模拟展开 |
| 书库与树菜单 | 进入约 160–200ms，退出约 100–140ms | 小位移，起点与触发位置关联；关闭动画期间不可继续操作 |
| 风格面板 | 沿用并校准现有约 180ms 过渡 | 不重复叠加另一套动画 |
| 全名提示 | 延迟触发，出现后保持静止 | 键盘可用，无循环滚动 |

- 复用 CSS、Web Animations API 和现有 motion 工具，不增加动效运行时依赖。
- 克制档主要做颜色、透明度与极小位移；完整档可增加轻微位移。关闭档直接到达最终状态，全名提示仍可使用。
- 保持现有用户偏好与系统减少动态效果的优先关系；本轮新增动效必须走统一解析后的策略，不各自发明开关。
- 快速反复打开、关闭、切换时应能中断或替换动画，不从错误的初态重播；业务状态不得依赖 animationend 才正确。
- 对当前条件卸载的弹层，补齐退出生命周期、焦点返回与事件清理；仅添加一个动效类名不视为完成。
- 键盘高频导航立即响应，不新增过渡等待。折叠、滚动、搜索和选中文档后保持阅读定位可预测。

## 7. 分阶段交付

1. **信息与布局**：两行书名、常驻说明行、文档标题与视图切换合并、底栏分组。先核对长标题、已阅和扫描版组合。
2. **视觉精修**：去重复边框，调整可读文字颜色、留白和选中态。查看明暗主题真实截图。
3. **交互手感**：补齐按钮反馈、菜单连续性、展开箭头与静止全名提示；检查快速反复操作和键盘路径。
4. **验收收口**：修复本轮发现的问题，汇总最终截图与实际验证结果。暂不向其他界面扩展同类改版。

四技能分工：UI UX Pro Max 核对信息层级和可读性；Redesign 排查重复组件轮廓；Emil 校准高频操作和动效连续性；Impeccable 统一视觉并做最终检查。规则冲突时，以用户已确认的方向、阅读器场景和仓库约束为准。

## 8. 验收标准

### 视觉与内容

- [ ] 图中的相似教材名获得明显更多辨认空间，长标题最多两行，完整标题有无需等待滚动的查看路径。
- [ ] 时长常驻说明行；PDF、EPUB、Markdown、扫描版、无法估计、已阅组合均正确。
- [ ] 文档行高一致，悬停、选中和提示出现不使邻项跳动。
- [ ] 顶部减少一层独立控制容器；格式标签没有描边。
- [ ] 当前文档、焦点、悬停和禁用能区分；小字对比度实际测量达标。
- [ ] 纸感明暗主题各一轮截图；抽查其他主题避免侧栏局部硬编码。
- [ ] 标准窗口与窄窗口检查，使用实际可达的侧栏宽度；Windows 常用缩放下无裁字或遮挡。

### 功能与交互

- [ ] 切库、刷新、搜索、合集、列表／书架、首页、统计、主题切换保持原功能。
- [ ] 键盘树导航、展开／收起、Esc、焦点返回、Ctrl+K、全名列表与 Alt+点击分栏可用。
- [ ] 拖动排序仍可发现和操作，拖拽结束不误触打开文档。
- [ ] 全名提示支持鼠标、键盘和关闭动效，不遮挡操作，不被容器裁切。
- [ ] 菜单快速反复切换不残留透明遮挡层、不丢焦点、不出现明显闪回。
- [ ] 三档动效及系统减少动态效果路径符合现有策略。
- [ ] 空库、无搜索结果、加载、失败、很多文档和嵌套文件夹状态均可用；不新增装饰填充。

### 验证命令与边界

- 实施后先运行实际改动对应的定向 Vitest 测试；涉及交互的回归应检查结果与可访问行为，不只断言 class 名。
- 完成后运行 `pnpm test`、`pnpm exec tsc --noEmit`、`pnpm build`。跨模块实施按仓库要求补 `cargo test --manifest-path src-tauri/Cargo.toml` 与 `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`。
- 共享界面改动完成后验证一次现有 `pnpm build:web` 构建兼容，不开展 Web 功能验收或发布。
- 运行一次与改动目标匹配的 Impeccable 检查，人工筛除误报；工具零告警不能代替视觉验收。
- 以有真实书库的 Tauri 窗口检查点击、滚动与动效；若只能检查浏览器模拟，应明确记录未验证项。

本文件是实施方案，不代表上述改动、测试或验收已经完成。
