# Reade 新手使用说明书

> 适用于 Reade 0.1.0 Windows 桌面版。文末单独说明 Web 版的差异。

Reade 是一款本地、只读的长文阅读器。你可以把装有 Markdown、PDF 或 EPUB 的文件夹交给 Reade，然后像使用个人电子书架一样浏览、搜索和阅读。Reade 不会修改书库里的原文件，也不会自动把文件上传到网络。

## 1 分钟快速上手

1. 打开 Reade，点击 **选择文档文件夹**。
2. 选择一个装有 `.md`、`.markdown`、`.mdx`、`.pdf` 或 `.epub` 文件的文件夹。
3. 在左侧文档列表中点击文件，开始阅读。

文档列表会先出现，全文检索索引会在后台继续建立。刚打开大型书库时，暂时搜不到全部内容是正常现象。

## 认识界面

在较宽的窗口中，Reade 分为三块：

```text
┌──────────────────┬──────────────────────────────┬──────────────────┐
│ 文档库           │ 正文                         │ 本文目录         │
│                  │                              │                  │
│ 选择/刷新文件夹  │ 文档标题、信息和阅读内容     │ Markdown 标题    │
│ 搜索框           │ PDF 工具栏                   │ PDF Outline      │
│ 文件夹和文档     │ 阅读进度                     │ EPUB 章节        │
│ 索引状态         │                              │                  │
└──────────────────┴──────────────────────────────┴──────────────────┘
```

- **左侧：文档库**。切换文件夹、搜索全文、展开目录并选择文档。
- **中间：正文**。阅读文档；页面顶部的细线显示阅读进度。
- **右侧：本文目录与标注**。目录可跳转标题、PDF 页或 EPUB 章节；「标注」列出高亮、下划线、笔记和书签。
- **右上角：阅读设置**。调整字号、行高、正文宽度、段距、字体和动态效果。
- **左下角：状态与主题**。查看文档数、索引进度，并切换浅色或深色主题。

窗口变窄时，本文目录和文档库会收进顶部按钮。点击 **文档库** 或 **本文目录** 图标即可展开；按 `Esc` 可以关闭抽屉和设置面板。

## 安装与第一次打开

### 安装 Windows 桌面版

1. 双击发布者提供的 `Reade_*_x64-setup.exe`。
2. 按安装向导完成安装。
3. 安装完成后打开 Reade。

当前安装包没有代码签名。Windows 可能显示 SmartScreen 提示。只有在安装包来自你信任的来源，并且文件校验值与发布者提供的一致时，才点击 **更多信息 → 仍要运行**；来源不明时应取消安装。

Reade 依赖 Microsoft Edge WebView2 Runtime。大多数 Windows 10/11 电脑已经安装；如果应用无法启动并提示缺少 WebView2，请先安装或修复 WebView2 Runtime。

### 选择文档库

“文档库”就是一个普通文件夹。Reade 会递归查看其中的子文件夹，并显示支持的文档。

- 点击欢迎页的 **选择文档文件夹**；也可以按 `Ctrl + O`。
- 以后点击左上角当前书库名称，可以更换文档库。
- Reade 会记住上次使用的书库，并在下次启动时重新打开。
- 点击书库名称右侧的刷新图标，可以立即重新扫描。

你不需要为 Reade 建立专用文件夹，也不需要复制文件。为了让列表更清楚，建议按主题或书名建立子文件夹。

## 支持哪些文件

| 格式 | 可以做什么 | 当前限制 |
| --- | --- | --- |
| Markdown：`.md`、`.markdown` | 排版阅读、目录、全文检索、表格、任务列表、脚注、公式、代码高亮、Mermaid 图表、本地图片 | 单个文件最大 10 MiB；建议使用 UTF-8 编码 |
| MDX：`.mdx` | 按普通 Markdown 安全阅读和检索 | 不执行 JSX、`import` 或脚本 |
| PDF：`.pdf` | 原版式连续滚动、文本选择、页码跳转、缩放、适宽、Outline、按页阅读模式与搜索跳页 | 不支持密码 PDF；不做 OCR；超过 128 MiB 只能用原版式阅读 |
| EPUB：`.epub` | Reade 排版、连续章节、目录、正文搜索跳章节、常见内嵌图片 | 只支持可重排 EPUB；不支持 DRM、fixed-layout、SVG、音视频和远程图片；最大 128 MiB |

Reade 不会显示 Office 文档、纯文本、漫画压缩包等其他格式。本版也不提供编辑、打印、导出或云同步。你可以在正文中划线高亮、添加下划线、短笔记和书签；标注保存在本机，不会改写文档库文件。

## 浏览文档库

### 用鼠标浏览

- 点击文件夹前的 `+` 展开，点击 `−` 收起。
- 文件名前的 `MD`、`MDX`、`PDF`、`EPUB` 标识表示文档格式。
- 点击文件名即可打开。
- 如果文件名旁出现小圆点，说明索引仍在建立、只完成了一部分、失败或不受支持。把鼠标停在圆点上可以查看原因。

### 用键盘浏览

先用 `Tab` 把焦点移到文档树，然后使用：

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` | 选择上一个或下一个项目 |
| `→` | 展开文件夹，或进入它的第一个项目 |
| `←` | 收起文件夹，或回到上一级 |
| `Home` / `End` | 跳到列表开头或结尾 |
| `Enter` / `空格` | 打开文档，或展开/收起文件夹 |

Reade 会自动感知书库中的文件变化。若你在别的软件中修改了当前文档，而正文没有立即更新，请点击刷新图标，再重新点击该文档。

## 搜索整个书库

1. 点击左上角的 **搜索标题与正文**，或按 `Ctrl + K`。
2. 输入关键词。Reade 会稍作等待后自动搜索；按 `Enter` 也可以立即搜索。
3. 点击结果打开文档。

不同格式的定位方式如下：

- Markdown/MDX：结果列表显示匹配片段；点击后打开命中的文档。
- PDF：结果显示页码，点击后直接跳到对应页。
- EPUB：结果显示“章节命中”，点击后直接跳到对应章节。

清空搜索框即可回到文档树。一次最多显示 100 条结果。

### 为什么刚打开书库时搜不到

打开书库后，Reade 会先快速显示文件树，再用单线程在后台提取文本。左下角会显示类似：

```text
索引 18/50 · 部分 1 · 失败 2
```

- **索引 18/50**：50 个文档中已有 18 个处理完成。
- **部分**：有些页面没有可提取文本，但其余内容仍可搜索。
- **失败**：文件损坏、受保护、格式不支持或读取失败。

当前打开的文档会优先处理。索引失败不会阻止一个仍能正常显示的 PDF 使用原版式阅读。

## 阅读 Markdown 和 MDX

Markdown 文档会使用 Reade 的统一排版。常见内容无需额外设置：

- 标题会出现在右侧 **本文目录** 中。
- 代码块支持语法高亮和 **复制** 按钮。
- 支持表格、任务列表、删除线、脚注和数学公式。
- Mermaid 代码块会显示为图表；超出安全限制或语法错误时会显示失败提示。
- 文档库内的相对链接可以跳到其他文档或当前章节。
- 外部网页、邮箱链接必须经过确认，才会交给系统浏览器或邮件应用。

为了安全，Reade 不执行 Markdown 或 MDX 中的原始 HTML、JavaScript、JSX 和导入语句。远程图片默认不会联网加载；越过当前书库边界的本地图片也会被拦截。

本地图片单个最大 25 MiB。图片无法显示时，先检查图片是否仍在当前书库内，以及 Markdown 中的相对路径是否正确。

## 阅读 PDF

打开 PDF 后，正文上方会出现专用工具栏。

### 原版式

**原版式**保留 PDF 的页面布局，适合论文、教材、表格和设计稿，也是默认模式。

- 点击左右箭头切换上一页或下一页。
- 在页码框中输入数字可直接跳页。
- 点击 `−` 或 `+` 缩小、放大，范围为 50%–300%。
- 点击百分比按钮恢复 **实际大小**（100%）。
- 点击 **适宽**，让页面宽度适合当前阅读区域。
- 右侧目录显示 PDF 自带的 Outline；没有 Outline 的 PDF 会提示无可导航标题。

Reade 只渲染视口附近的页面。长 PDF 滚动时，远处页面暂时只保留空白占位是正常现象，滚到附近后会重新显示。

### 阅读模式

**阅读模式**按页提取文字，再用 Reade 的长文排版显示，适合连续阅读文字型 PDF。

- 在原版式和阅读模式之间切换时，Reade 会尽量保持当前页和页内位置。
- 搜索结果会定位到 `Page N` 对应的页面。
- 如果页面是扫描图片或文字无法提取，页面会明确显示“需要 OCR”或缺页范围。
- 阅读模式中的内容可能与原版式的复杂表格、分栏和图文位置不同；需要核对版面时请切回原版式。

以下情况无法使用阅读模式：

- PDF 超过 128 MiB。
- PDF 需要密码或受到保护。
- 文本索引失败且重试后仍无法提取。

Reade 当前不提供 OCR。扫描版 PDF 可以尝试原版式阅读，但扫描页面不会进入全文检索，也不会被标成“已完整提取”。

## 阅读 EPUB

Reade 不直接加载电子书自带的网页和样式，而是提取章节、段落、列表、表格、引用、代码和脚注，再用 Reade 的排版显示。

- 所有章节连续排列，可以像长文一样向下滚动。
- 右侧 **本文目录** 显示章节；点击后直接跳转。
- 搜索结果可以直接定位到命中的章节，并短暂高亮。
- 常见的 PNG、JPEG、GIF、WebP 内嵌图片可以显示。
- 外部链接仍会先询问是否打开。

为避免电子书携带的网页代码影响电脑安全，Reade 会用占位提示替代远程图片、不安全资源和首版未开放的资源。书内附件、SVG、脚本、表单、iframe、音视频等不会执行或直接渲染。

下列 EPUB 会明确提示不支持，而不是降级为不安全的网页显示：

- DRM 或其他受保护电子书。
- fixed-layout（固定版式）EPUB。
- 损坏或缺少必要目录信息的 EPUB。
- 大于 128 MiB 的 EPUB。

## 调整阅读体验

点击右上角齿轮按钮打开 **阅读设置**。

| 设置 | 范围或选项 | 适合什么情况 |
| --- | --- | --- |
| 正文字号 | 13–26 px | 字太小或希望一屏显示更多内容 |
| 正文行高 | 1.40–2.40 | 长文阅读时增加或减少行间留白 |
| 最大正文宽度 | 560–1600 px，最右为“随窗口” | 窄版心读长文，宽版心看表格和代码 |
| 段落间距 | 0.5×–2.0× | 调整段落之间的呼吸感 |
| 字体风格 | 系统均衡、清晰无衬线、书刊衬线 | 技术文档或书刊阅读偏好 |
| 动态效果 | 关闭、克制、完整 | 减少动画，或显示全部轻量反馈 |

**恢复默认**会恢复默认排版，并根据 Windows 当前的“减少动态效果”偏好选择“关闭”或“克制”。浅色/深色主题不会被这个按钮重置。

阅读设置、主题和已展开的文件夹会保存在本机。文档滚动位置只在当前应用会话中保存；关闭 Reade 后，不保证回到上次的精确阅读位置。

### 三档动态效果的区别

- **关闭**：没有位移和过渡；跳转立即完成；加载图标保持静止，但文字状态仍会更新。
- **克制**：使用短暂淡入和最多约 4 px 的轻微位移，适合日常阅读。
- **完整**：显示本版全部微动效，但仍不使用弹跳、粒子或大面积动画。

PDF 页面、PDF 文本层和 EPUB 正文本身不会被加入动画，避免长文滚动时分心或影响性能。

## 索引缓存与隐私

为了让下次搜索更快，Reade 会把提取出的文本和索引保存在 Windows 的应用缓存目录中。它不会把 PDF、EPUB 或 Markdown 原文件复制进缓存，也不会改写你的书库。

- 缓存采用约 1 GiB 的软上限，并优先清理最久未使用的旧书库索引。
- 当前正在使用的书库会受到保护，因此缓存有时可能暂时超过软上限。
- 文件大小或修改时间变化后，对应旧索引会失效并重新建立。
- 切换书库时，旧书库未完成的索引任务会停止。

需要释放空间或处理异常索引时：

1. 打开 **阅读设置**。
2. 点击 **清理文档索引缓存**。
3. 等待成功提示；Reade 会在后台为当前书库重新建立索引。

这个操作只删除可重新生成的派生文本和搜索索引，不删除书库里的任何文件。

| --- | --- |
| `Ctrl + O` | 选择或更换本地文档库 |
| `Ctrl + K` | 聚焦全文搜索框 |

## 常见问题

### 选择文件夹后没有看到文档

依次检查：

1. 文件扩展名是否为 `.md`、`.markdown`、`.mdx`、`.pdf` 或 `.epub`。
2. Markdown 文件是否超过 10 MiB；超出限制的 Markdown 不会进入列表。
3. 文件是否位于 `.git`、`node_modules`、`dist`、`build`、`target` 等自动排除的开发目录中。
4. 文件是否被该目录的 `.gitignore` 规则忽略。
5. 文件是否只通过指向书库外部的符号链接出现；Reade 不跟随符号链接。
6. 点击左上角刷新图标重新扫描。

### 能打开文档，但搜索不到内容

- 先看左下角索引是否仍在进行。
- 打开该文档，当前文档会被提到索引队首。
- 如果标题下方出现错误，点击 **重试索引**。
- 扫描 PDF 没有文字层，当前版本无法通过 OCR 补全。
- 仍有问题时，进入阅读设置清理索引缓存，再等待重新建立。

### PDF 的“阅读模式”按钮不可用

常见原因是文件超过 128 MiB，或者该 PDF 受到密码保护。你仍可尝试使用原版式；受保护文件会直接显示不支持原因，不会要求输入或保存密码。

### PDF 某些页显示缺失

这通常表示页面只有扫描图片、字体编码特殊或文字无法提取。原版式页面仍可能正常显示。阅读模式和搜索只使用成功提取的文字，并会标明缺失范围。

### EPUB 打不开

Reade 首版只支持可重排 EPUB。DRM、fixed-layout、加密条目、损坏容器或超过 128 MiB 的文件会明确报错。你可以在有权限的前提下，使用电子书来源提供的普通可重排、无 DRM 版本。

### 图片显示“已拦截”或占位提示

- Markdown：确认图片在当前书库内，路径正确，且单个文件不超过 25 MiB。
- EPUB：远程图片、SVG 和不安全资源首版不会显示。
- Reade 不会为了补图而自动联网。

### 点击外部链接时为什么要确认

确认框可以防止文档在你不知情时打开网页或唤起其他应用。请先检查显示的地址；不认识或不信任的链接请选择取消。

### 清理缓存会删除我的书吗

不会。它只删除 Reade 生成的搜索索引和派生文本。你的 Markdown、PDF、EPUB 和图片仍留在原文件夹中。标注保存在独立表中，清理转换缓存时不会删除。

### 如何添加高亮、下划线、笔记和书签

正文标题上方顶栏右侧有荧光笔图标按钮（阅读设置左侧）。点击后展开标注工具：

- **浏览**：选中文字后出现浮动工具条，可「高亮」「笔记」或「书签」。
- **高亮 / 下划线**：选中文字后立即按当前颜色落笔；高亮与下划线各自记住上次颜色。处于这些模式时，顶栏荧光笔按钮会保持高亮提示。
- **撤销**：面板「撤销」或 `Ctrl+Z`（输入框内除外）可撤销最近一次创建、删除或清空。
- **清空**：面板或侧栏「清除本文档标注」会二次确认后删光当前文档标注。

在侧栏「标注」列表中可为高亮/下划线改颜色、编辑笔记或删除。添加笔记与编辑笔记共用同一对话框。也可使用 `Ctrl+B` 在当前阅读位置添加书签。`Esc` 可退出高亮/下划线模式并关闭面板。右侧面板可在「目录」与「标注」之间切换，点击条目即可跳回；若正文变更导致无法定位，条目会标「定位失效」。

## 桌面版和 Web 版的区别

| 能力 | Windows 桌面版 | Web 版 |
| --- | --- | --- |
| 文档来源 | 你选择的本地文件夹 | 站点发布者预先构建的公开内容 |
| 支持格式 | Markdown、MDX、PDF、可重排 EPUB | Markdown、MDX |
| 搜索 | 本机后台索引 | 构建站点时生成搜索数据 |
| 标注 | Markdown / PDF / EPUB 高亮、下划线、笔记与书签（本机 SQLite） | 仅 Markdown（浏览器 IndexedDB） |
| 隐私边界 | 文档留在本机 | 发布到站点的内容是公开内容 |
| 选择文件夹 | 支持 | 不支持 |

如果你是站点维护者，需要发布 Reade Web，请阅读 [Web 发布说明](WEB_DEPLOY.md)。

## 使用边界速查

Reade 当前**可以**：

- 本地只读浏览 Markdown、MDX、PDF 和可重排 EPUB。
- 在整个书库中搜索，并准确跳到 PDF 页或 EPUB 章节。
- 划线高亮、下划线、短笔记与书签（右侧「标注」列表可跳转与管理；支持撤销与清空本文档）。
- 调整适合自己的排版、主题和微动效。
- 安全显示本地内容，并在打开外链前请求确认。

Reade 当前**不可以**：

- 编辑源文档、打印或导出文档。
- OCR 识别扫描 PDF。
- 打开密码 PDF、DRM EPUB 或固定版式 EPUB。
