# Reade 新手使用说明书

> 适用于 Reade 0.1.0 Windows 桌面版。文末单独说明 Web 版的差异。

Reade 是一款本地、只读的长文阅读器。你可以把装有 Markdown、PDF 或 EPUB 的文件夹交给 Reade，然后像使用个人电子书架一样浏览、搜索和阅读。Reade 不会修改书库里的原文件，也不会自动把文件上传到网络。

## 1 分钟快速上手

1. 打开 Reade，点击 **选择文档文件夹**。
2. 选择一个装有 `.md`、`.markdown`、`.mdx`、`.pdf` 或 `.epub` 文件的文件夹。
3. 在左侧文档列表中点击文件，开始阅读。

文档列表会先出现，全文检索索引会在后台继续建立。刚打开大型书库时，暂时搜不到全部内容是正常现象。

## 认识界面

在较宽的窗口中，Reade 分为三块：

```text
┌──────────────────┬──────────────────────────────┬──────────────────┐
│ 文档库           │ 正文                         │ 本文目录         │
│                  │                              │                  │
│ 选择/刷新文件夹  │ 文档标题、信息和阅读内容     │ Markdown 标题    │
│ 搜索框           │ PDF 工具栏                   │ PDF Outline      │
│ 文件夹和文档     │ 阅读进度                     │ EPUB 章节        │
│ 索引状态         │                              │                  │
└──────────────────┴──────────────────────────────┴──────────────────┘
```

- **左侧：文档库**。切换文件夹、搜索全文、展开目录并选择文档。
- **中间：正文**。阅读文档；页面顶部的细线显示阅读进度。
- **右侧：本文目录与标注**。目录可跳转标题、PDF 页或 EPUB 章节；「标注」列出高亮、下划线、笔记和书签。
- **右上角：阅读设置**。调整字号、行高、正文宽度、段距、字体和动态效果。
- **左下角：状态与主题**。查看文档数、索引进度；点击系列名（如「纸感」）选择界面风格，点击房子图标打开主页，点击日/月图标切换浅色或深色。

窗口变窄时，本文目录和文档库会收进顶部按钮。点击 **文档库** 或 **本文目录** 图标即可展开；按 `Esc` 可以关闭抽屉和设置面板。

## 安装与第一次打开

### 安装 Windows 桌面版

1. 双击发布者提供的 `Reade_*_x64-setup.exe`。
2. 按安装向导完成安装。
3. 安装完成后打开 Reade。

当前安装包没有代码签名。Windows 可能显示 SmartScreen 提示。只有在安装包来自你信任的来源，并且文件校验值与发布者提供的一致时，才点击 **更多信息 → 仍要运行**；来源不明时应取消安装。

Reade 依赖 Microsoft Edge WebView2 Runtime。大多数 Windows 10/11 电脑已经安装；如果应用无法启动并提示缺少 WebView2，请先安装或修复 WebView2 Runtime。

### 选择文档库

“文档库”就是一个普通文件夹。Reade 会递归查看其中的子文件夹，并显示支持的文档。

- 点击欢迎页的 **选择文档文件夹**；也可以按 `Ctrl + O`。
- Reade 会记住上次使用的书库，并在下次启动时重新打开。
- 点击书库名称右侧的刷新图标，可以立即重新扫描。

你不需要为 Reade 建立专用文件夹，也不需要复制文件。为了让列表更清楚，建议按主题或书名建立子文件夹。

### 最近书库：多个书库之间一键切换

Reade 会记住最近打开过的 8 个书库（路径、文档数和上次打开时间），存在本机：

- 欢迎页的 **最近打开** 列表：点击卡片直接打开对应书库。
- 阅读中点击左上角当前书库名称，会弹出 **最近书库** 菜单：点选即切换，菜单底部的 **选择新文件夹…** 可打开目录选择对话框。
- `Ctrl + O` 的行为保持不变，永远直接弹出目录选择对话框。
- 移动硬盘拔掉、文件夹改名等导致路径不可访问时，对应条目会灰显并标注「路径不可访问」；点条目旁的 × 可以把它从列表移除。
- 打开动作与手选文件夹完全一致：仍会重新扫描并校验目录，列表只是记住路径的备忘录。

最近书库列表只在桌面版出现；Web 版没有文件夹概念，不显示该列表。

## 支持哪些文件

| 格式 | 可以做什么 | 当前限制 |
| --- | --- | --- |
| Markdown：`.md`、`.markdown` | 排版阅读、目录、全文检索、表格、任务列表、脚注、公式、代码高亮、Mermaid 图表、本地图片 | 单个文件最大 10 MiB；建议使用 UTF-8 编码 |
| MDX：`.mdx` | 按普通 Markdown 安全阅读和检索 | 不执行 JSX、`import` 或脚本 |
| PDF：`.pdf` | 原版式连续滚动、文本选择、页码跳转、缩放、适宽、Outline、按页阅读模式与搜索跳页 | 不支持密码 PDF；不做 OCR；超过 128 MiB 只能用原版式阅读 |
| EPUB：`.epub` | Reade 排版、连续章节、目录、正文搜索跳章节、常见内嵌图片 | 只支持可重排 EPUB；不支持 DRM、fixed-layout、SVG、音视频和远程图片；最大 128 MiB |

Reade 不会显示 Office 文档、纯文本、漫画压缩包等其他格式。本版也不提供编辑、打印、导出或云同步。你可以在正文中划线高亮、添加下划线、短笔记和书签；标注保存在本机，不会改写文档库文件。

## 主页：从上次的位置继续

点击左下角的房子图标即可打开主页；再点一次返回正文。主页回答的是「我现在读什么」——阅读统计负责回顾，主页负责行动。

桌面版启动时，如果当前书库已经有阅读痕迹（记住的阅读位置，或最近 30 天的阅读记录），Reade 会先落在主页，而不是自动打开第一篇文档；全新的书库保持原有行为，仍直接打开第一篇。

主页由几张卡片组成：

- **继续阅读**。最近 30 天读过、且仍在当前书库中的文档（最多 5 篇），显示格式、上次阅读时间、累计时长和读到的进度。点击任意一条立即回到正文继续读。
- **今日进度**（仅桌面版）。今天已读的时长；设定每日目标后还会显示目标环和完成百分比，连续阅读多天时会一并展示。
- **库内新动态**。自上次访问主页以来书库中新增或修改的文档。离开主页后基准点前移，下次访问重新计数。
- **那年今日**（有历史痕迹时）。一年前和一个月前的今天各成一组：优先展示当天划下的高亮/下划线摘录（点击跳回原文中的标注处），不足三条时补上当天读了 5 分钟以上的文档。按本地日历日对齐（如 3 月 31 日的「一个月前」落在 2 月末日）；两个日子都没有痕迹时整卡隐藏，新书库不会看到空卡片。已删除或已失联文档的标注不出现。

回到正文的方式：点击主页里的任意文档卡片、点击左侧文档树中的文档，或再次点击左下角的主页按钮。

配合主页，Reade 会跨启动记住每篇文档读到的位置（只保存在本机浏览器存储中）：重启应用或刷新 Web 版后再次打开同一篇文档，会自动回到上次读到的地方。位置按比例换算，字号或窗口大小变化后只能近似还原；想精确回到某一段，书签仍是最可靠的锚点。

Web 版说明：主页在两端都可用。Web 版不记录阅读时长，所以「继续阅读」改按最近的阅读位置排序，「今日进度」卡不显示，「那年今日」只有标注组、没有文档补位；通过 `?doc=` 分享链接打开的页面不受主页影响，仍会直达对应文档。

## 每日回顾：把划过的句子再递到眼前

Reade 会把你划过的高亮和下划线（含笔记）自动放进回顾池；书签和空摘录不参与。主页的「今日回顾」卡显示今天到期的数量，点击 **开始回顾** 进入全屏回顾视图：

- 每天默认最多 10 条，多本书的摘录会交错出现；完成一批后可点 **再来一批** 继续。
- 每张卡片显示摘录原文、笔记和来源。点 **记住了**，这条会隔更久再出现（1 → 3 → 7 → 14 → 30 → 60 天）；点 **再看一次**，明天再来。到期不回顾没有任何惩罚，队列每天重新取样。
- **主动回忆（挖空）**。卡片上方可切换卡片样式：**摘录**（默认，完整显示摘录，与过去一致）、**挖空**（摘录中最显著的片段被胶囊遮住，先自己回想，点击胶囊或按 `空格` 揭示后才能评分）、**混合**（每张卡按固定规则在两种样式间二选一，同一条标注永远同一种样式）。摘录太短或挖不出合适片段的卡片自动按摘录样式显示；样式选择会被记住。挖空只改变卡片的显示方式，不影响到期节奏。
- **打开原文** 跳回文档中的标注处；同一天内回到回顾视图会从中断处继续。
- **不再回顾** 需要确认，此后这条不再进入队列（本版不提供恢复入口）。
- 键盘：`1` 或 `空格` = 记住了，`2` = 再看一次，`Enter` = 打开原文，`Esc` = 退出；挖空卡揭示前 `空格` = 揭示答案（此时 `1`/`2` 暂不可用，`Enter`/`Esc` 照常）。

新划的标注从第二天起进入回顾。回顾进度只保存在本机（桌面版 SQLite，Web 版浏览器 IndexedDB）；删除标注后，对应的回顾记录也会随之清理。

## 读书报告：把一本书的收获编纂成一页

读完一篇长文或一本书后，右侧「标注」tab 顶部的 **读书报告** 按钮可以把当前文档的全部摘录按章节结构穿插成一页只读报告：

- 结构与目录一致：章节标题下依次列出该章的高亮/下划线摘录（带颜色点）、你的笔记（斜体）与位置信息；没有标注的章节自动跳过，无法归属章节的摘录（文首选区、标题已改名）收进末尾的「未归属章节」。
- 书签没有摘录文本，不进入报告，统计行会注明「已略过 N 条书签」；没有目录的文档退化为按顺序平铺的摘录列表。
- 点击任意条目立即关闭报告并跳回原文中的标注处。
- **导出 Markdown** 把整页报告下载为 `.md` 文件（`#` 文档、`##` 章节、`>` 摘录），可直接投入任何笔记软件。
- 全屏「全库标注」中枢里，当前文档分组的组头也有 **编纂读书报告** 入口；其他文档请先打开再编纂（报告依赖该文档已加载的目录）。
- 报告随开随算、不保存；`Esc` 或左上角返回即可回到阅读。桌面版与 Web 版都可用。

## 全库标注：检索、筛选与导出

右侧面板的「全库」tab 汇总当前书库的所有标注，并按文档分组：

- 顶部搜索框对全库标注做全文检索（摘录、笔记与书签标题；桌面版走本机索引，Web 版在浏览器内过滤）。类型（高亮/下划线/书签）与四色语义 chip（默认「金句/疑问/行动/术语」）是纯筛选，和检索结果叠加生效；计数行显示「命中 N 条，来自 M 个文档」。
- 全屏中枢左列常显「颜色语义」图例，提示每种颜色当前的含义。
- 组头可折叠；每组默认显示前 20 条，点「展开全部」查看其余。组头的 **导出该文档** 把该文档的标注以 Markdown 摘录复制到剪贴板；检索或筛选激活时，全局导出按钮变为 **导出当前结果**。
- 已移动或删除的文档，其标注会灰显在列表末尾的失联分组中：仍可查看与导出，但不能跳转；若文件仍在书库内的新位置，刷新书库后 Reade 会提示迁移标注。
- 点击 tab 顶部的 **在中枢中打开** 进入全屏「全库标注」视图：左列是检索、筛选与文档快捷定位，右列是分组卡片流，窄窗口自动退化为单列。点击任意条目仍会跳回原文。

## 目录热力：让目录变成密度地图

右侧「本文目录」不只是位置列表：

- 有标注的章节，条目右缘会出现一枚小色点，颜色越深表示该节标注越多（与阅读统计的热力色阶同一套语义）。把鼠标停在条目上可看到「本节 N 条标注」；新增或删除标注后即时更新。
- 无法归属到章节的标注（文首选区，或标题已改名的旧标注）会在目录顶部汇总为一行「文首或已变更章节另有 N 条标注」，点击可回到文档顶部。
- 读到过的章节，条目左缘会出现一道细线（依据每篇文档记住的最远阅读位置）。这只是「读到过哪里」的轻提示，没有打卡或进度考核的含义。

三种格式都支持：Markdown 按标题归属，PDF 按 Outline 页码区间归属，EPUB 按章节聚合。没有可导航标题的文档（如无 Outline 的 PDF）不显示热力。

## 知识地图：这个库我读了多少（桌面版）

阅读统计视图底部有一张**知识地图**——一整块矩形按目录切成大大小小的瓦片：

- **面积 = 文本量**：每块的大小与文档的索引字符数成正比（还没索引到的文档暂按文件大小估算），一眼看出库里哪一片体量最大。
- **色深 = 到达覆盖率**：颜色越深表示你在该文档读到过的位置越靠后（滚动或翻页的最远位置折算，与目录热力同一套色阶）。浅色瓦片就是「还荒着」的部分。
- **点击文件夹瓦片下钻**该层重新铺开，顶部面包屑或「返回上一级」按钮随时回来；**点击文档瓦片直接打开原文**。键盘 `Tab` 到瓦片后回车同样可用。
- 把鼠标停在瓦片上，地图下方会显示名称、字数、覆盖率和包含的文档数；单层瓦片过多时自动聚合为「其他」块。

覆盖率只表示「滚到过哪里」，不代表读懂了多少。该地图与阅读时长记录无关，即使还没有任何阅读统计也会显示。

## 文档地图：右缘的一条刻度带

打开文档后，正文右缘（紧贴滚动条内侧）会出现一层细小的刻度，把「这篇文档里我留下过什么」变成一张可点击的地形图：

- **标注**：高亮与下划线按四色显示为圆点，颜色语义与你的标注体系一致。
- **书签**：显示为强调色的小方块。
- **搜索命中**：库搜索后打开命中的 PDF 或 EPUB 时，命中页/章节会显示为空心圆；Markdown 的搜索索引没有文档内位置，不显示这类刻度。
- **朗读位置**：朗读进行时有一条横线实时标出当前句，句子前进横线随之移动。

把鼠标停在刻度上可以看到类型与摘录开头；点击刻度即可跳转（标注与书签走精确定位，其余按比例滚动）。刻度位置在字号调整、窗口变化或标注增删后自动重算；同一行的多笔同色标注会合并为一枚，超过 200 枚时均匀抽稀显示——地图只是显示层，侧栏「标注」列表永远是完整清单。

不需要它时，在 **阅读设置 → 文档地图** 里关闭即可（默认开启）。

## 聚焦模式：只看正在读的那一段

**阅读设置 → 聚焦模式** 提供三个相互独立的专注开关（默认全部关闭，可任意组合）：

- **段落聚焦**：当前阅读的段落保持全亮，其余段落降为半透明；滚动时焦点自动跟随视口中部偏上的位置。切换的淡入淡出时长跟随「动态效果」档位（关闭档为瞬时）。
- **打字机滚动**：用滚轮或方向键、翻页键阅读时，停顿片刻后当前段落会自动对齐到视口中部，视线不必追着文字跑。拖动滚动条时不吸附；朗读进行中由朗读自己的跟随接管，打字机暂时让位。
- **阅读标尺**：一条跟随鼠标指针的横向淡色带，高度等于当前行高，帮助长行阅读时锁定视线；不拦截任何点击，触屏设备上不启用。

三种格式的适用范围：Markdown、EPUB 与 PDF 的**阅读模式**都支持；PDF **原版式**没有段落结构，三个开关在原版式下置灰并提示。开关状态保存在本机，桌面版与 Web 版通用。

## 竖排模式（实验）：古文与诗词的从右往左

**阅读设置 → 竖排模式** 可以把当前 Markdown 或 EPUB 文档改为竖排阅读：文字竖着排、行从右往左推进，滚动方向随之变成横向（滚轮向下滚 = 向左前进），适合古文、诗词类内容。这是一个**实验功能**，按文档记忆——只有你明确开启过的文档才竖排，其余文档不受影响。

- **支持范围**：Markdown 与 EPUB。PDF 版式由页面画布决定、MDX 不在实验范围内，这两类文档的开关会置灰并说明原因。
- **横排孤岛**：代码块、数学公式、表格、Mermaid 图表和图片在竖排流中保持横排显示，内部滚动照常，不会被竖着掰断。
- **数字与英文**会随竖排侧倒，首版不做纵中横处理。

竖排是围绕"读"收窄的体验，部分依赖纵向滚动轴的功能在竖排开启时会**暂停**（开关下方的提示也会列出）：

| 功能 | 竖排下状态 |
| --- | --- |
| 标注（高亮/下划线/笔记/书签）、选区工具条与编辑气泡 | 可用 |
| 目录点击跳转、文内锚点、搜索/标注/书签/增量重读跳转 | 可用 |
| 朗读播放与句级高亮 | 可用（自动跟随滚动暂停） |
| 阅读进度条 | 可用（按横向滚动换算） |
| 分栏对照 | 主栏可竖排；副栏恒为横排 |
| 聚焦模式（段落聚焦/打字机滚动/阅读标尺） | 暂停，开关置灰并提示 |
| 文档地图刻度层 | 暂停，不显示 |
| 目录跟随高亮 | 暂停（点击跳转仍可用） |
| 阅读位置记忆 | 暂停：竖排下不记录、每次从开头读起；横排下记住的位置原样保留 |
| 读完接着读 | 暂停，不弹推荐卡 |

遇到任何显示问题，关闭开关即可完全恢复横排与全部功能——这是实验档的第一响应方式。

## 阅读时间预估：这篇还要读多久

Reade 会在三个位置给出估算的阅读时长，帮你决定「现在读哪篇」：

- 左侧文档树的条目右侧显示「约 N 分钟」（窗口较窄时自动隐藏）。
- 主页「继续阅读」卡显示「剩余约 N 分钟」，按你已读到的最远位置折算。
- 右侧目录顶部显示「全文约 N 分钟」。

时长基于文档的索引文本字数：桌面版刚打开新书库时使用默认速度档（500 字/分钟）；随着阅读记录积累（近 90 天、至少 5 篇读过的文档），Reade 会按你的实际速度校准，目录顶部会标注「个人速度已校准」。速度统计取中位数并限制在合理区间，偶尔挂机不会污染估算。

几点说明：

- 估算值仅供参考，「约」字是认真的；跳读、精读的差异不会被建模。
- 扫描版 PDF（多数页面没有文本层）不显示预估，避免用失真的字数误导。
- Web 版始终使用默认速度档（浏览器中没有阅读时长记录）。

## 读完接着读：末尾的下一篇推荐

滚动到一篇文档的末尾并稍作停留，右下角会浮出一张轻卡片，推荐「下一篇」；点击即刻打开，摁 × 或 `Esc` 关闭后本篇文档在本次会话内不再出现。

推荐来源按优先级三级回落，卡片上的徽标会注明本次推荐的依据：

1. **合集顺序**：当前文档属于某个合集时，推荐合集里的下一条（失联条目自动跳过；已是最后一条则进入下一级）。属于多个合集时按最近更新的合集判断。
2. **同文件夹**：按左侧文档树同样的排序，推荐同一文件夹里的下一篇；已是本文件夹最后一篇时不跨文件夹跳跃。
3. **关联最多**：与当前文档互链的文档里，链接次数最多且还没读完的那一篇。

几点说明：

- 它与主页的「继续阅读」分工不同：那是"回到读了一半的文档"，这是"读完当前这篇后接着读什么"。
- 卡片只在真正滚到底（阅读高水位 ≥98%）并驻留约一秒后出现，中途上翻会自动收起；朗读进行中不会弹出。
- Markdown、PDF、EPUB 都适用；短到无需滚动的文档不会触发。
- 不想要它时，在 **阅读设置 → 读完接着读** 里整体关闭（默认开启）。

## 增量重读：这篇改过哪里（桌面版）

重新打开一篇你读过、之后又被修改过的文档时，正文顶部会浮出一条提示：**自上次阅读后有更新**，并写明变化规模（如「2 段修改、1 段新增」）。发生变化的段落会在左缘标出一条细线，帮你只重读改动的部分：

- **下一处**：在变化的段落/章节之间循环跳转（Markdown 按段落，EPUB 按章节；PDF 只提示「第 X 页有变化」，不做行内标记）。
- **知道了**：关闭提示，并把当前版本记为「已读」——下次再打开，只有再次被修改才会重新提示。
- 第一次阅读某篇文档不会有提示；打开并停留约半分钟，或离开该文档时，Reade 会自动记住「你读到的版本」。
- 判定基于段落文本比对：纯排版调整（如改空行）通常不会误报；改动极多时会退化为一句「有大量更新」的整体提示。
- 「上次已读版本」只是从索引派生的文本快照，存放在应用缓存目录（独立的约 256 MiB 限额，最久未读的先清理），不复制原文件、不改写书库；清理索引缓存会连同它一起清除。
- 桌面版专属：Web 版的站点内容由发布者统一构建，不做逐人阅读记录。

## 金句卡片：把这句话带走

选中一段文字后，浮动工具条会多出一个 **卡片** 按钮：点击即可把这段文字排成一张随当前界面主题取色的引文卡片（PNG 图片），出处一行自动写上文档标题和生成日期。

- 预览浮层里有两档版式可切：**素笺**（左对齐、带引号装饰）与 **衬线中轴**（衬线居中）。预览图就是导出物本身，所见即所得。
- 主按钮 **复制图片** 把 PNG 写进剪贴板，可直接粘贴到聊天或笔记应用；复制被系统拦截时可改用 **下载 PNG** 保存文件。
- 已有的高亮和下划线也能回头做卡：在右侧「标注」列表或点击正文标注弹出的编辑气泡里点 **卡片** 即可（书签没有摘录，不提供此入口）。
- 引文过长时会自动截断并在浮层里提示。卡片不会被保存成记录——它是即用即走的输出，不是新的数据。

## 阅读报告卡片：本地版年度总结

阅读统计视图（左下角进入统计后）右上角的星形按钮可以生成一组"阅读报告"图片卡——完全在本机聚合、渲染，数据不出网：

- 周期三档：**本月 / 今年 / 上一年**。某周期的活跃阅读日不足 7 天时按钮禁用（悬停可见原因），攒够再来。
- 固定四张卡：**总览**（累计时长、活跃天数、最长连续、读过文档数、划下标注数、较上期变化）、**习惯**（最常阅读时段、单日最长、格式占比）、**书单**（读得最久 Top3 + 划线最多 Top3）、**金句**（该期内最长的一条摘录；期内没有标注时这张自动缺席）。
- 卡片随当前界面主题（四系列 × 明暗）取色，预览即导出物本身。缩略图条可逐张切换；**复制本张** 把 PNG 写进剪贴板，**下载本张 / 全部下载** 保存文件（文件名如 `reade-report-2026-总览.png`）。
- 对比上期指上一个自然月/自然年；上期没有记录时会写明"上期无记录"而不是百分比。
- 报告不会被保存——随点随生成，数据源就在本机的阅读记录与标注里。仅桌面版提供（Web 版没有阅读时长记录）。

## 朗读：把正文交给系统语音

打开文档后，顶部工具区的 **朗读** 按钮会用系统语音逐句朗读正文，当前句子以选区色高亮并自动滚动跟随。

- **只使用本地语音**：Reade 只枚举 `本地合成` 的系统语音，任何联网语音一律过滤——正文永远不会被发往网络。这也意味着 **音质完全取决于系统里已安装的语音**（Windows 可在「设置 → 时间和语言 → 语音」里添加），与浏览器在线语音的自然度存在差距，属于离线承诺的固有代价。
- 没有检测到本地语音时按钮呈禁用态，把鼠标停上去可看到原因。
- 控制条提供播放/暂停、上一句/下一句、从头朗读、语速（0.5–2.0×）与语音选择；语速和语音偏好会被记住。朗读中按 `Esc` 立即停止。
- 默认从当前视口附近的句子开始；代码块、公式和表格会自动跳过。
- Markdown、EPUB 与 PDF 的 **阅读模式** 均可朗读；PDF 原版式暂不支持，点朗读时会提示一键切换到阅读模式。
- 桌面版的朗读时间计入阅读统计（听完即读过）。

## 相关段落：这件事我还在哪写过

选中至少 8 个字符后，浮动工具条会出现 **相关** 按钮：点击即可在整个书库里寻找谈论同一件事的其他段落（当前文档自动排除）。

- 结果浮层最多列 12 条，每行是文档标题、格式徽标和上下文摘录；PDF 命中会标注页码，点击即可跳转到对应文档/页面/章节。
- 匹配基于词面重叠（与全文搜索同一套本机索引），不是语义相似——选中越具体的句子，结果越准。
- 桌面版和 Web 版都可用；两端的排序可能略有差异。

## 文档链接：谁链到了这篇

右侧面板的第四个 tab「链接」把 Markdown 文档之间的引用关系变成双向视图：

- **反向链接**：哪些文档链到了当前文档，按来源分组并显示链接文本摘录与次数，点击跳到来源文档。PDF/EPUB 虽不解析出链，但同样能看到自己的反向链接。
- **出链**：当前 Markdown 文档指向库内的链接。在库的目标可点击跳转；目标缺失时灰显「目标不在库中」；`[[wiki]]` 链接按文件名匹配，同名多候选时显示候选数、不自动挑选。
- 顶部的断链计数只统计文档目标；图片等资产不计入。
- 一切只读：Reade 不改写任何文档。Web 版在文档数超过 500 时会停用此视图并显示说明。

### 悬停预览：点过去之前先看一眼

把鼠标停在链接上约半秒，会浮出一张小小的预览卡，帮你决定要不要真的跳过去：

- **正文里的库内链接**：显示目标文档的标题、格式与开头一段文字；链接带 `#章节` 时，摘录会尽量从对应标题之后开始（按标题文字匹配，改过名的旧锚点可能仍从开头展示）。目标是 PDF 时额外显示总页数。
- **脚注引用**：悬停 `[^1]` 这类引用会就地显示脚注内容，不用跳到文末再跳回来。
- **侧栏「链接」tab 的条目**：反链与出链行同样支持悬停预览；`[[wiki]]` 链接在正文中按纯文本显示，想预览它的目标请在这里悬停。
- 预览是纯文字摘录（不渲染图片、公式或图表），最多约 600 字；移开鼠标、滚动页面或按 `Esc` 即消失；键盘将焦点移到链接上稍候也会触发。点卡片底部的 **打开 →** 等于点击该链接。
- 外部网页链接不会出预览卡，悬停它们也绝不会联网；索引尚未就绪的文档会显示「索引尚未就绪」而不是空白。触屏设备上此功能不生效。

## 合集：跨文件夹的阅读清单

文件夹是存放结构，合集是阅读结构。侧栏文档树上方的「合集」分区可以把散落各处的文档组成命名清单（例如「考研数学」收数学真题 PDF 和错题笔记）：

- 点「+」新建合集；展开合集后组头提供 **重命名** 与 **删除**。删除合集只删清单——文档、标注、进度都不受影响（确认弹层也会写明）。
- 把文档加入合集：打开该文档，点顶部工具区的 **加入合集**，在弹出面板里勾选或新建。
- 条目行显示格式徽标、标题和阅读进度徽标（Markdown/EPUB 显示百分比，PDF 显示读到的页码）；把鼠标停在条目上可 **上移/下移/移出**。
- 合集名旁的 `在库数/总数` 徽标反映清单健康度；被移动或删除的文档会灰显保留，不会被自动清理。文件移动后经「失联文档」重绑确认，合集条目会跟着批注一起迁移。

## 分栏对照：左边工作台，右边参考资料

窗口宽度 ≥1080px 时，顶部工具区的 **分栏对照** 按钮可以把阅读面分成左右两栏：

- 左栏（主栏）保持全功能：批注、目录跟随、搜索跳转、阅读进度都只属于主栏。右栏（副栏）是纯净的参考面——三种格式都能读、能独立滚动翻页，但不做批注。
- 点按钮默认在右栏打开当前文档（同一篇两处对照零成本）；文档树或搜索结果 **Alt+点击** 可把任意文档送进右栏。副栏内点击库内链接在副栏内自行跳转，不打扰主栏。
- 拖拽中缝分割条调整比例（30%–70%），分割条聚焦后也可用 `←`/`→` 微调。
- 窗口变窄（<1080px）时自动退回单栏、主栏保留；拉宽后自动恢复分栏和副栏文档。分栏布局不跨重启保存。

## 浏览文档库

### 用鼠标浏览

- 点击文件夹前的 `+` 展开，点击 `−` 收起。
- 文件名前的 `MD`、`MDX`、`PDF`、`EPUB` 标识表示文档格式。
- 点击文件名即可打开。
- 如果文件名旁出现小圆点，说明索引仍在建立、只完成了一部分、失败或不受支持。把鼠标停在圆点上可以查看原因。

### 用键盘浏览

先用 `Tab` 把焦点移到文档树，然后使用：

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` | 选择上一个或下一个项目 |
| `→` | 展开文件夹，或进入它的第一个项目 |
| `←` | 收起文件夹，或回到上一级 |
| `Home` / `End` | 跳到列表开头或结尾 |
| `Enter` / `空格` | 打开文档，或展开/收起文件夹 |

Reade 会自动感知书库中的文件变化。若你在别的软件中修改了当前文档，而正文没有立即更新，请点击刷新图标，再重新点击该文档。

### 书架：把库摊开成一面封面墙

文档树上方有一组"树形 / 书架"切换。切到**书架**后，同一批文档变成网格卡片：封面 + 标题 + 格式徽标，读过的书右下角有进度角标（滚动类文档显示读到的百分比，PDF 按页数折算）。点击卡片即打开，`Alt + 点击`在右侧分栏打开；选择会记住，下次启动仍是你上次用的形态。排序与文档树一致（文件夹内容按目录顺序展开）。

封面来自三种途径，全部自动生成、不用你配置：

- **PDF**：卡片进入视野后，Reade 在本机渲染第 1 页做成缩略图并缓存（进的是可随时清理的索引缓存，同样受 1 GiB 治理）；第二次进书架直接秒开。
- **EPUB**：打开过一次的书会从书内插图中挑选封面（优先文件名带 cover 的图）缓存下来；还没打开过的先用生成式封面。
- **Markdown / MDX 及一切拿不到图的情况**：按标题生成一张确定性的主题色渐变封面（同一标题永远同一张脸），并随界面风格与明暗主题变色。

Web 版书架不渲染 PDF/EPUB 缩略图，统一使用生成式封面。

## 命令面板：键盘直达一切

按 `Ctrl + P` 呼出命令面板：一个输入框加一列结果，输入几个字就能模糊匹配三类条目——

- **文档**：按标题或路径匹配当前书库的全部文档（显示格式徽标），回车立即打开。
- **合集**：匹配合集名，回车在左侧栏展开该合集清单。
- **命令**：常用动作直接执行——切换浅色/深色、四个界面风格、打开主页、开启/退出分栏、开始/停止朗读、打开阅读设置、聚焦全文搜索、刷新或更换文档库。只显示当前可用的命令。

匹配支持中文子串与英文缩写（如输入 `rdme` 可命中 `README`），多个词之间是"都要命中"的关系，可以混合中英文（如 `数学 pdf`）。`↑`/`↓` 选择、`Enter` 执行、`Esc` 关闭；面板在窄窗口同样可用。

## 跳走了怎么回来：阅读回退栈

点搜索结果、双链、相关段落、合集、命令面板、文档树或本文目录跳转时，Reade 会先记住你出发的位置。随后：

- `Alt + ←` 后退：回到跳转前的文档和位置（Markdown/EPUB 精确到滚动位置，PDF 精确到页码与页内位置）；连续跳转可以连续后退。
- `Alt + →` 前进：后退多了再原路返回。
- 正文顶部工具区左侧有对应的 **后退/前进** 按钮，没有历史可走时按钮呈禁用态。

历史只在当前会话内有效（最多 50 步），更换文档库后清空。文档内的目录跳转和 `[链接](#锚点)` 跳转同样会被记录——点完目录想回到刚才读的段落，按一下 `Alt + ←` 即可。

## 搜索整个书库

1. 点击左上角的 **搜索标题与正文**，或按 `Ctrl + K`。
2. 输入关键词。Reade 会稍作等待后自动搜索；按 `Enter` 也可以立即搜索。
3. 点击结果打开文档。

不同格式的定位方式如下：

- Markdown/MDX：结果列表显示匹配片段；点击后打开命中的文档。
- PDF：结果显示页码，点击后直接跳到对应页。
- EPUB：结果显示“章节命中”，点击后直接跳到对应章节。

清空搜索框即可回到文档树。一次最多显示 100 条结果。

### 为什么刚打开书库时搜不到

打开书库后，Reade 会先快速显示文件树，再用单线程在后台提取文本。左下角会显示类似：

```text
索引 18/50 · 部分 1 · 失败 2
```

- **索引 18/50**：50 个文档中已有 18 个处理完成。
- **部分**：有些页面没有可提取文本，但其余内容仍可搜索。
- **失败**：文件损坏、受保护、格式不支持或读取失败。

当前打开的文档会优先处理。索引失败不会阻止一个仍能正常显示的 PDF 使用原版式阅读。

## 阅读 Markdown 和 MDX

Markdown 文档会使用 Reade 的统一排版。常见内容无需额外设置：

- 标题会出现在右侧 **本文目录** 中。
- 代码块支持语法高亮和 **复制** 按钮。
- 支持表格、任务列表、删除线、脚注和数学公式。
- Mermaid 代码块会显示为图表；超出安全限制或语法错误时会显示失败提示。
- 文档库内的相对链接可以跳到其他文档或当前章节。
- 外部网页、邮箱链接必须经过确认，才会交给系统浏览器或邮件应用。

为了安全，Reade 不执行 Markdown 或 MDX 中的原始 HTML、JavaScript、JSX 和导入语句。远程图片默认不会联网加载；越过当前书库边界的本地图片也会被拦截。

本地图片单个最大 25 MiB。图片无法显示时，先检查图片是否仍在当前书库内，以及 Markdown 中的相对路径是否正确。

## 阅读 PDF

打开 PDF 后，正文上方会出现专用工具栏。

### 原版式

**原版式**保留 PDF 的页面布局，适合论文、教材、表格和设计稿，也是默认模式。

- 点击左右箭头切换上一页或下一页；主栏也可以用 `A` / `D` 翻页（双页开启时按“对”翻，与箭头一致）。
- `Shift+A` / `Shift+D` 按步长快翻（默认 10 页，不按对）。工具栏页码组里的数字芯片可在 5 / 10 / 20 之间循环，只在本次会话有效。
- 在页码框中输入数字可直接跳页。封面或前言占用了文件页时，点 **标定**（或 `Ctrl+Shift+G`）告诉 Reade「当前文件第 N 页对应印刷第 L 页」：之后页码框、页角和阅读模式的 `Page N` 都显示印刷页，输入也按印刷号跳转。右侧的 `/ 总页数` 仍是 PDF 文件总页。前置页（印刷号小于 1）会回退显示文件页，不会出现 0 或负数。标定存在本机，与阅读进度分开；分栏打开同一篇时两边共用。标注、搜索和目录仍使用文件页。
- `G` 聚焦页码框，便于直接打页码。
- **主线** 跳到这篇 PDF 已记录的最远文件页（`Shift+H`）；当前已在最远页时按钮不可用。若你想从现在这里重新起算进度，可用命令面板的「将主线设为当前页」或 `Ctrl+Shift+H`（覆盖率会后退）。
- 点击 `−` 或 `+` 缩小、放大，范围为 50%–300%。
- 点击百分比按钮恢复 **实际大小**（100%）。
- 点击 **适宽**，让页面宽度适合当前阅读区域。
- 右侧目录显示 PDF 自带的 Outline；没有 Outline 的 PDF 会提示无可导航标题。

Reade 只渲染视口附近的页面。长 PDF 滚动时，远处页面暂时只保留空白占位是正常现象，滚到附近后会重新显示。

#### 双页并排：宽窗下像摊开的书

窗口足够宽（≥1180px 且阅读区放得下两个可读页面）时，原版式工具栏的 **双页** 按钮可以把页面两两并排：

- 第 1 页单独成行靠右（书籍封面是右页），之后按 (2, 3)、(4, 5) 配对，正符合书籍装订语义——跨页大图不会被拆错对。
- 上一页/下一页按钮改为按"对"翻动；页码框仍显示和接受单页页码，跳页、搜索定位、标注都精确到单页。
- **适宽** 在双页下表示"两页加上间距恰好填满阅读区"；切换双页/单页时会自动重新适宽。
- 窗口拖窄后自动回到单页（按钮同时置灰）；再拖宽会自动恢复双页。每篇文档的双页偏好在本次会话内被记住。
- 双页仅属于原版式；阅读模式是连续文本流，没有"页"的并排概念。

### 截取引用：把 PDF 的一块区域做成卡片

原版式工具栏最右侧的 **截取引用** 按钮进入框选模式（再点一次或按 `Esc` 退出）：

- 光标变为十字，在任意已渲染的页面上拖出一个矩形，松手即弹出 **引用卡片** 预览——所选区域的位图配上自动出处行「《文档标题》 · 第 N 页」，随当前界面主题取色。
- **复制图片** 把 PNG 写进剪贴板，**下载 PNG** 保存文件（文件名如 `reade-引用-书名-p12.png`）；再次框选生成新的一张。
- 对无法选中文字的扫描版 PDF 尤其有用：图表、公式、影印段落都能"摘"下来。缩得很小时截取，Reade 会自动对该页做一次高清重渲后再裁剪，保证卡片清晰。
- 框选期间文字选择暂时停用，退出模式后恢复；太小的拖拽（约 24px 以内）视为误触忽略。
- 截取不会保存为标注——它和金句卡片一样是即用即走的输出。仅原版式提供（阅读模式有真文字，直接用金句卡片）。

### 阅读模式

**阅读模式**按页提取文字，再用 Reade 的长文排版显示，适合连续阅读文字型 PDF。

- 在原版式和阅读模式之间切换时，Reade 会尽量保持当前页和页内位置。
- 搜索结果会定位到 `Page N` 对应的页面。
- 如果页面是扫描图片或文字无法提取，页面会明确显示“需要 OCR”或缺页范围。
- 阅读模式中的内容可能与原版式的复杂表格、分栏和图文位置不同；需要核对版面时请切回原版式。

以下情况无法使用阅读模式：

- PDF 超过 128 MiB。
- PDF 需要密码或受到保护。
- 文本索引失败且重试后仍无法提取。

Reade 当前不提供 OCR。扫描版 PDF 可以尝试原版式阅读，但扫描页面不会进入全文检索，也不会被标成“已完整提取”。

## 阅读 EPUB

Reade 不直接加载电子书自带的网页和样式，而是提取章节、段落、列表、表格、引用、代码和脚注，再用 Reade 的排版显示。

- 所有章节连续排列，可以像长文一样向下滚动。
- 右侧 **本文目录** 显示章节；点击后直接跳转。
- 搜索结果可以直接定位到命中的章节，并短暂高亮。
- 常见的 PNG、JPEG、GIF、WebP 内嵌图片可以显示。
- 外部链接仍会先询问是否打开。

为避免电子书携带的网页代码影响电脑安全，Reade 会用占位提示替代远程图片、不安全资源和首版未开放的资源。书内附件、SVG、脚本、表单、iframe、音视频等不会执行或直接渲染。

下列 EPUB 会明确提示不支持，而不是降级为不安全的网页显示：

- DRM 或其他受保护电子书。
- fixed-layout（固定版式）EPUB。
- 损坏或缺少必要目录信息的 EPUB。
- 大于 128 MiB 的 EPUB。

## 调整阅读体验

点击右上角齿轮按钮打开 **阅读设置**。

| 设置 | 范围或选项 | 适合什么情况 |
| --- | --- | --- |
| 正文字号 | 13–26 px | 字太小或希望一屏显示更多内容 |
| 正文行高 | 1.40–2.40 | 长文阅读时增加或减少行间留白 |
| 最大正文宽度 | 560–1600 px，最右为“随窗口” | 窄版心读长文，宽版心看表格和代码 |
| 段落间距 | 0.5×–2.0× | 调整段落之间的呼吸感 |
| 字体风格 | 系统均衡、清晰无衬线、书刊衬线 | 技术文档或书刊阅读偏好 |
| 动态效果 | 关闭、克制、完整 | 减少动画，或显示全部轻量反馈 |

**恢复默认**会恢复默认排版，并根据 Windows 当前的“减少动态效果”偏好选择“关闭”或“克制”。浅色/深色主题不会被这个按钮重置。

阅读设置、主题和已展开的文件夹会保存在本机。文档滚动位置只在当前应用会话中保存；关闭 Reade 后，不保证回到上次的精确阅读位置。

### 界面风格

界面配色分为「风格系列」和「浅色/深色」两个独立维度：

- 点击左下角的系列名（如「纸感」）打开 **界面风格** 面板，每个系列显示一张色卡，点击即刻生效。
- 点击旁边的日/月图标只切换浅色或深色，不改变所选系列。

当前提供四个系列：

| 系列 | 气质 | 适合什么 |
| --- | --- | --- |
| 纸感 | 暖纸底、红陶强调色（默认） | 通用阅读 |
| 墨韵 | 更暖的纸、更深的墨、靛青强调色 | 书籍式沉浸长读 |
| 清透 | 冷灰极简、冷蓝强调色 | 技术文档和代码密集的 Markdown |
| 青瓷 | 低饱和浅绿底、茶褐强调色 | 护眼久读、光线复杂环境 |

切换系列会同时套用该系列的字体预设：墨韵使用「书刊衬线」，纸感、清透和青瓷使用「系统均衡」。之后你仍可在阅读设置中手动改回任意字体；手动选择会一直保留，直到下一次切换系列。切换浅色/深色不会改变字体。

当「动态效果」为「完整」时，点击日/月图标或风格面板色卡切换主题，会从按钮位置以一圈"墨水晕开"式的圆形扩散揭示新主题；从命令面板等无明确位置的入口切换时，则是一次轻柔的全屏淡入淡出。「克制」和「关闭」档保持瞬时切换。浏览器不支持 View Transitions 时（如旧版 Firefox 的 Web 版），完整档自动回落为瞬时切换。

代码块在所有系列中都保持深色底，PDF 页面始终保持原版式的白底；批注的黄、绿、蓝、粉四色也不随系列变化，换风格后旧标注仍然可辨认。

### 三档动态效果的区别

- **关闭**：没有位移和过渡；跳转立即完成；加载图标保持静止，但文字状态仍会更新。
- **克制**：使用短暂淡入和最多约 4 px 的轻微位移，适合日常阅读。
- **完整**：显示本版全部微动效，但仍不使用弹跳、粒子或大面积动画。

PDF 页面、PDF 文本层和 EPUB 正文本身不会被加入动画，避免长文滚动时分心或影响性能。

## 索引缓存与隐私

为了让下次搜索更快，Reade 会把提取出的文本和索引保存在 Windows 的应用缓存目录中。它不会把 PDF、EPUB 或 Markdown 原文件复制进缓存，也不会改写你的书库。

- 缓存采用约 1 GiB 的软上限，并优先清理最久未使用的旧书库索引。
- 当前正在使用的书库会受到保护，因此缓存有时可能暂时超过软上限。
- 「增量重读」的上次已读文本快照也存放在这里，但有自己独立的约 256 MiB 限额，不挤占上面的索引空间。
- 文件大小或修改时间变化后，对应旧索引会失效并重新建立。
- 切换书库时，旧书库未完成的索引任务会停止。

需要释放空间或处理异常索引时：

1. 打开 **阅读设置**。
2. 点击 **清理文档索引缓存**。
3. 等待成功提示；Reade 会在后台为当前书库重新建立索引。

这个操作只删除可重新生成的派生文本和搜索索引，不删除书库里的任何文件。

## 常见问题

### 选择文件夹后没有看到文档

依次检查：

1. 文件扩展名是否为 `.md`、`.markdown`、`.mdx`、`.pdf` 或 `.epub`。
2. Markdown 文件是否超过 10 MiB；超出限制的 Markdown 不会进入列表。
3. 文件是否位于 `.git`、`node_modules`、`dist`、`build`、`target` 等自动排除的开发目录中。
4. 文件是否被该目录的 `.gitignore` 规则忽略。
5. 文件是否只通过指向书库外部的符号链接出现；Reade 不跟随符号链接。
6. 点击左上角刷新图标重新扫描。

### 能打开文档，但搜索不到内容

- 先看左下角索引是否仍在进行。
- 打开该文档，当前文档会被提到索引队首。
- 如果标题下方出现错误，点击 **重试索引**。
- 扫描 PDF 没有文字层，当前版本无法通过 OCR 补全。
- 仍有问题时，进入阅读设置清理索引缓存，再等待重新建立。

### PDF 的“阅读模式”按钮不可用

常见原因是文件超过 128 MiB，或者该 PDF 受到密码保护。你仍可尝试使用原版式；受保护文件会直接显示不支持原因，不会要求输入或保存密码。

### PDF 某些页显示缺失

这通常表示页面只有扫描图片、字体编码特殊或文字无法提取。原版式页面仍可能正常显示。阅读模式和搜索只使用成功提取的文字，并会标明缺失范围。

### EPUB 打不开

Reade 首版只支持可重排 EPUB。DRM、fixed-layout、加密条目、损坏容器或超过 128 MiB 的文件会明确报错。你可以在有权限的前提下，使用电子书来源提供的普通可重排、无 DRM 版本。

### 图片显示“已拦截”或占位提示

- Markdown：确认图片在当前书库内，路径正确，且单个文件不超过 25 MiB。
- EPUB：远程图片、SVG 和不安全资源首版不会显示。
- Reade 不会为了补图而自动联网。

### 点击外部链接时为什么要确认

确认框可以防止文档在你不知情时打开网页或唤起其他应用。请先检查显示的地址；不认识或不信任的链接请选择取消。

### 清理缓存会删除我的书吗

不会。它只删除 Reade 生成的搜索索引和派生文本。你的 Markdown、PDF、EPUB 和图片仍留在原文件夹中。标注保存在独立表中，清理转换缓存时不会删除。

### 如何添加高亮、下划线、笔记和书签

正文标题上方顶栏右侧有荧光笔图标按钮（阅读设置左侧）。点击后展开标注工具：

- **浏览**：选中文字后出现浮动工具条，可「高亮」「笔记」或「书签」。
- **高亮 / 下划线**：选中文字后立即按当前颜色落笔；高亮与下划线各自记住上次颜色。处于这些模式时，顶栏荧光笔按钮会保持高亮提示。
- **撤销**：面板「撤销」或 `Ctrl+Z`（输入框内除外）可撤销最近一次创建、删除或清空。
- **清空**：面板或侧栏「清除本文档标注」会二次确认后删光当前文档标注。

在侧栏「标注」列表中可为高亮/下划线改颜色、编辑笔记或删除。添加笔记与编辑笔记共用同一对话框。也可使用 `Ctrl+B` 在当前阅读位置添加书签。`Esc` 可退出高亮/下划线模式并关闭面板。右侧面板可在「目录」与「标注」之间切换，点击条目即可跳回；若正文变更导致无法定位，条目会标「定位失效」。

### 给四种颜色起名字

黄/绿/蓝/粉四色各有一个可自定义的语义名，默认为「金句（黄）、疑问（绿）、行动（蓝）、术语（粉）」。名字会出现在颜色选择器的悬停提示、全库标注的颜色筛选 chip 和中枢图例中，让四色成为你自己的标注体系：

- 在 **阅读设置 → 标注颜色命名** 中修改，每个名字最多 6 个字符；清空某项即恢复该色默认名，「恢复默认命名」一键全部还原。
- 命名只是展示层：标注数据本身仍按颜色保存，导出内容不受影响；桌面版与 Web 版分别记住各自的命名。

## 桌面版和 Web 版的区别

| 能力 | Windows 桌面版 | Web 版 |
| --- | --- | --- |
| 文档来源 | 你选择的本地文件夹 | 站点发布者预先构建的公开内容 |
| 支持格式 | Markdown、MDX、PDF、可重排 EPUB | Markdown、MDX |
| 搜索 | 本机后台索引 | 构建站点时生成搜索数据 |
| 标注 | Markdown / PDF / EPUB 高亮、下划线、笔记与书签（本机 SQLite） | 仅 Markdown（浏览器 IndexedDB） |
| 隐私边界 | 文档留在本机 | 发布到站点的内容是公开内容 |
| 选择文件夹 | 支持 | 不支持 |
| 段落分享链接 | 不提供（无可分享 URL） | 选中文字 → 工具条「链接」复制段落深链 |

### Web 版：安装与离线阅读

Web 版是一个可安装的 PWA：在 Chrome/Edge 地址栏可以选择「安装」，把阅读库变成独立窗口的应用。读过的内容会自动离线可用：

- 打开过的文档（以及文档树与搜索数据）会缓存在浏览器里，断网后仍可阅读；
- 离线时打开没读过的文档会提示「联网打开一次后即可离线阅读」；
- 站点更新后，联网访问一次即自动换到新版本，无需手动清缓存。

### Web 版：分享指向某一段的链接

在 Web 版里选中一段文字后，浮动工具条会多出一个「链接」按钮：点击即把一条 `?doc=文档#text=…` 链接写入剪贴板。对方打开链接时，页面会在文档渲染完成后自动滚动到这段文字并短暂高亮。

- 链接携带选区的前 120 个字符（空白会被归一化）；过长的选区自动截断。
- 与既有的 `?doc=文档#章节` 链接互不影响；一条链接只指向章节或段落之一。
- 如果目标文档后来被修改、这段文字已不存在，页面会提示「链接指向的段落未找到，文档可能已更新」，而不是静默停在开头。

### Web 版：手机上的阅读手势

在手机等窄屏触控设备上打开 Web 版时，界面会自动切换到移动布局：

- **底部工具条**：文档树、本文目录、搜索、明暗主题与「更多」五个大按钮固定在屏幕底部（拇指可达）；向下滚动阅读时工具条自动半隐、向上滚动即回。「更多」打开命令面板，可直达阅读设置、界面风格、朗读、切换文档等全部动作。
- **屏缘轻扫**：从屏幕最左缘向右轻扫打开文档树抽屉，从最右缘向左轻扫打开本文目录抽屉；反向轻扫或点暗色遮罩即可关闭。如果轻扫与浏览器自身的返回手势冲突，底部工具条按钮是等价入口。
- **长按选字标注**：用系统的长按选字选中正文后，浮动标注工具条会自动出现，高亮、下划线、笔记、书签与复制段落链接都可直接点按；移动语境下所有触控目标不小于 44px。

这些手势只在 Web 版的窄屏触控环境生效，桌面版与宽窗浏览器行为完全不变。

如果你是站点维护者，需要发布 Reade Web，请阅读 [Web 发布说明](WEB_DEPLOY.md)。

## 使用边界速查

Reade 当前**可以**：

- 本地只读浏览 Markdown、MDX、PDF 和可重排 EPUB。
- 在整个书库中搜索，并准确跳到 PDF 页或 EPUB 章节。
- 划线高亮、下划线、短笔记与书签（右侧「标注」列表可跳转与管理；支持撤销与清空本文档）。
- 调整适合自己的排版、主题和微动效。
- 安全显示本地内容，并在打开外链前请求确认。

Reade 当前**不可以**：

- 编辑源文档、打印或导出文档。
- OCR 识别扫描 PDF。
- 打开密码 PDF、DRM EPUB 或固定版式 EPUB。
- 转换或阅读 Word、Excel、PowerPoint 等 Office 文件。
- 自动同步、登录账号或自动更新。

遇到错误时，请保留屏幕上的完整错误文字、文件格式、文件大小和操作步骤。这些信息比只说“打不开”更容易帮助开发者定位问题；不要发送包含隐私内容的原文件，除非你明确愿意分享。
