# Reade 阅读样章

> 一款只把注意力放在文字、结构与阅读节奏上的本地 Markdown 阅读器。

这份样章用于验证中文长文、英文混排、目录定位与扩展语法。正文不离开本机，阅读状态也只保存在本地。

## 为什么从阅读开始

多数 Markdown 工具把编辑器放在舞台中央。Reade 的选择相反：让工具退后，让文字占据稳定而舒适的版心。中文正文需要略大的行高，英文和数字需要可靠的 fallback；标题、段落、引用之间还要有清晰但不过度的节奏。

一个合适的阅读宽度并非固定像素。它会随字号、窗口和语言变化。默认版心以约 42–48 个汉字为目标，并允许在阅读设置中调整。

行内代码如 `cargo tauri build` 应当清楚但不抢眼。外部链接需要交给系统浏览器打开，例如 [Tauri](https://tauri.app/)。
