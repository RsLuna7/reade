# 长文阅读的节奏

## 版心与留白

阅读界面并不是把网页塞进桌面窗口。左侧文档树负责建立位置感，中间只承担阅读，右侧目录负责长文导航。三栏各自滚动，正文位置不应因为切换文件夹而突然跳动。

## 标题层级

标题采用宋体或系统衬线字体，正文采用清晰的无衬线字体。二者的对比来自字形、字重与留白，而不是夸张的字号。

### 三级标题

三级标题是正文内部的路标。它应该能被快速扫到，也不该切断段落连续性。

#### 四级标题

更深层级减少视觉权重。目录会保留缩进，帮助读者理解结构。

## 代码与技术文档

```ts
type ReadingSettings = {
  fontSize: number;
  lineHeight: number;
  measure: number;
};
```

代码块允许横向滚动，并提供复制按钮。高亮器延迟加载，普通文字不会为此等待。
