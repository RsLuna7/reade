# 聚焦模式演示长文

这篇文档专门用来体验「阅读设置 → 聚焦模式」的三个开关：段落聚焦、打字机滚动与阅读标尺。它足够长，能让你在滚动中观察焦点段落的切换节奏。

## 一、为什么需要段落聚焦

长文阅读时，视线常常在段落之间游移。屏幕上同时呈现的文字越多，注意力被分散的可能性越大。段落聚焦把当前段落之外的内容降为半透明，让眼睛自然回到正在读的那一段。

它不是把其余内容藏起来，而是降低它们的视觉权重。你仍然能看到上下文的轮廓，需要时扫一眼就能回忆起前后文的位置。

聚焦的判定跟随视口中部偏上的一条隐形参考线。向下滚动时，进入这条线的段落会亮起，离开的段落则淡出，整个过程由动效档位控制节奏。

> 引用块也是一个整体块：当参考线落在引用上时，整段引用保持全亮，而不是逐句切换。

## 二、打字机滚动的由来

打字机滚动这个名字来自机械打字机：纸张向上走，正在敲击的那一行永远停在同一个高度。阅读时的对应体验是——你正在读的行保持在视口中部，视线不必追着文字跑。

开启后，用滚轮或方向键、翻页键移动阅读位置，停顿片刻，当前段落会被轻轻对齐到视口中部。拖动滚动条做大范围跳转时不会吸附，避免与你的意图相抗。

- 滚轮小步前进：停顿后自动对齐；
- `PageDown` 大步翻页：同样在停顿后校正；
- 拖动滚动条：完全不干预。

## 三、阅读标尺是什么

阅读标尺是一条跟随鼠标指针的横向淡色带，高度恰好等于当前行高。它模拟手指或直尺压在纸面上的感觉，帮助长行文本的换行回扫。

标尺不响应任何点击——它只是视觉辅助层，选字、点链接、划高亮都不受影响。把指针移出正文区域，标尺随之消失。

调大字号或行高后，标尺高度会自动跟随变化，始终罩住恰好一行。

## 四、三者如何组合

三个开关相互独立，可以任意组合。以下是几种常见搭配：

1. 只开段落聚焦：适合精读论证性长文；
2. 段落聚焦 + 打字机滚动：沉浸式逐段推进，视线固定在屏幕同一区域；
3. 只开阅读标尺：适合宽版心的技术文档，防止换行串行；
4. 三者全开：最大限度的专注，代价是屏幕上的"动静"稍多。

组合没有对错，取决于当下的阅读任务。设置会被记住，下次打开应用保持原样。

## 五、一段可以慢慢读的文字

下面这些段落没有信息密度上的野心，它们存在的意义就是让你滚动。

窗外的天色由亮转暗，屏幕的底色也随之从纸白换成墨蓝。文字在光的两端之间来回迁徙，句读之间藏着呼吸的节奏。

读书这件事，快与慢并无高下。快读取其骨架，慢读得其血肉。工具能做的，是让快时不迷路，慢时不倦怠。

一段落成一件事。段与段之间的空白，是给眼睛的台阶，也是给思绪的缓冲。

代码块在聚焦模式里同样按整块处理：

```python
def focus(paragraph, others):
    """当前段落全亮，其余降为半透明。"""
    paragraph.opacity = 1.0
    for block in others:
        block.opacity = 0.35
```

表格也是一个块级单位：

| 开关 | 作用对象 | 关闭时 |
| --- | --- | --- |
| 段落聚焦 | 当前段落之外的块 | 全文等亮 |
| 打字机滚动 | 滚动停顿后的位置 | 不吸附 |
| 阅读标尺 | 指针所在的一行 | 无色带 |

## 六、更多可滚动的段落

第六章的每一段都很短，方便观察焦点在段落之间的快速切换。

春有百花秋有月，夏有凉风冬有雪。

若无闲事挂心头，便是人间好时节。

读到这里，试着用方向键向下走几行，感受打字机滚动把行高对齐到视口中部的动作。

再试着把鼠标缓缓下移，看阅读标尺如何贴着指针滑动。

段落聚焦此刻应该正把这一段点亮，而上下两段安静地退到了背景里。

## 七、收尾

聚焦模式的三个开关都在「阅读设置」面板里，随时可以整体关闭，回到最朴素的阅读面。

如果你在 PDF 原版式里打开设置面板，会看到这三个开关处于置灰状态——原版式没有段落结构，聚焦模式在那里帮不上忙；切换到阅读模式即可使用。

祝阅读愉快。
